## 🚀 How to Run

Make sure **Python 3** is installed on your system.

Clone the repository:

```bash
git clone https://github.com/shivansh570/python-assignments.git
```

Navigate to the repository:

```bash
cd python-assignments
```

Run an assignment:

```bash
python p1.py
```
